An assembly-line beverage automation system driven by an Arduino Mega, stepper motors, and sensor feedback. The goal was repeatable, precise dispensing — both for QA validation and for demonstration purposes.

Stepper-driven peristaltic pumps control fluid volume per dispense with sub-milliliter precision. Flow and temperature sensors provide real-time feedback with closed-loop correction. Safety interlocks prevent operation outside defined parameters. A web interface allows recipe programming and monitoring without touching the hardware directly.
