# Personal Site

An Astro 5 portfolio and technical blog for zackdell.com.

- **Pages and content**: Astro pages and Markdown content live under `src/`.
- **Development**: `npm ci`, then `npm run dev`.
- **Production build**: `npm run build` outputs the static site to `dist/`.
- **Deployment**: GitHub Actions publishes `master` to GitHub Pages. The `workflow_dispatch` trigger allows a production deploy without a source change.
